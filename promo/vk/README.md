# VK/OK Promo Pack

Upload `icon/icon-576x576.png` as the application icon and
`cover/cover-1120x630.png` as the horizontal listing image.

The screenshot folders contain three selected real-gameplay images in each
required orientation:

- `screenshots/landscape/`: 1200x600 PNG files.
- `screenshots/portrait/`: 600x1200 PNG files.

The selection covers a layered board, a hard grand endless board, and the
matching-partner interaction. `manifest.json` records source captures,
transform details, and SHA-256 hashes. `review/contact-sheet.png` is QA-only
and should not be uploaded.

Listing art is derived from the approved text-free game-owned masters in the
parent promo pack. Screenshots are derived from deterministic Playwright
gameplay captures and preserve the complete HUD and playfield.
